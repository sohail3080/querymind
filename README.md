## Project Overview

This project focuses on developing a system that allows users to ask questions in plain English and automatically converts those questions into SQL queries. The generated SQL queries are then executed on a MySQL database to retrieve accurate results.

## Objective

The main objective of this system is to bridge the gap between technical and non-technical users by enabling natural language interaction with databases.

## Use Case

Business users can query databases without needing to know SQL. By simply asking questions in everyday language, they can access and analyze data quickly and efficiently. This makes data more accessible to non-technical team members and improves overall decision-making within the organization.
